关于 Feynman Lab

让值得做的想法变成现实。

人们有想法，我们把其中一些做出来。

把好奇心付诸实践。

Feynman Lab 是一个小型实验性软件实验室。人们把希望存在的工具、网站、自动化程序和其他实用软件想法告诉我们。

我们会根据价值、可行性、时间与兴趣自主选择少数想法。提交不代表一定会开发。

发布项目时，我们希望它能为更多人所用，并展示问题、可用工具及尽可能公开的源码。

谁在运营实验室？

Feynman Lab 是一个独立软件项目。你可以通过公开的 GitHub 组织查看网站源码与讨论，也可以通过提交页的邮箱联系我们。项目刚刚起步，目前尚未发布创办人介绍。

查看公开 GitHub 组织 ↗

为什么不收开发费？

我们自主选题，制作希望让更多人使用的工具。自主选择的空间让免费模式成为可能。提出想法的人是可能性的贡献者，而不是委托私人软件的客户。

项目仍处于早期，并没有成熟收入。长期希望实用工具和相关内容带来自然访问，通过广告及其他不向提交者收费的收入支持后续开发。如果模式发生变化，我们会明确说明。
