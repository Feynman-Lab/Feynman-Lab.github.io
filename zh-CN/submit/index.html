提出一个值得实现的想法。

告诉我们一个小问题，以及你希望出现的软件。提交免费；是否探索和开发，由实验室自主决定。

分享你的想法

不需要技术方案。

这些信息能帮助我们理解：

  1. 你希望什么东西存在？
  2. 它能为谁解决什么问题？
  3. 有没有参考案例？
通过邮件发送想法 ↗

点击会打开邮件应用，并附上几个提示。你也可以直接写信到 torres4koo@gmail.com.

更愿意公开分享？在 GitHub Discussions 发帖 ↗

需要登录 GitHub。公开帖子所有人都能看到，请不要包含敏感信息。

什么适合实验室？

聚焦单一问题、可能帮助更多人的网页工具、浏览器扩展、自动化脚本，以及文件或数据工具。

私有企业系统、大型应用、紧急交付和高度个性化的定制需求通常不合适。

之后会怎样？

我们会考虑想法是否能帮助不止一个人、是否可行、范围是否合适，以及当前时间。如果想进一步探索，我们会联系你讨论。无法保证回复每一份投稿，也无法承诺时间表。

提交不代表入选。入选项目不收开发费，但它属于实验室自主开展的项目，不是委托开发。

隐私与公开

邮件会发送到我们的邮箱，不会自动公开。邮箱地址用于回复；请勿发送密码或机密资料。

GitHub Discussions 是公开的，需要 GitHub 账号；发布的内容任何人都可以阅读。

入选想法可能成为公开工具，代码也可能开源。开发前我们会讨论范围；未经同意，不会公开你的私人邮件或身份信息。
