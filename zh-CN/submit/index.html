从一个想法开始

告诉我们你需要什么。

小工具、网站、浏览器扩展、自动化程序，或难以归类的点子都可以。用自己的话说明问题就好。

分享你的想法

不需要技术方案。

这些信息能帮助我们理解：

  1. 你希望什么东西存在？
  2. 它能为谁解决什么问题？
  3. 有没有参考案例？
通过邮件发送想法 ↗

点击会打开邮件应用，并附上几个提示。你也可以直接写信到 torres4koo@gmail.com.

更愿意公开分享？在 GitHub Discussions 发帖 ↗

需要登录 GitHub。公开帖子所有人都能看到，请不要包含敏感信息。

之后会怎样？

我们会评估需求，选择有用、可实现且符合当前时间安排的项目。如果选中你的想法，我们会联系你了解细节。

提交想法免费，选中的项目也免费开发。我们无法保证每个需求都会实现，也无法为每个需求承诺时间。
