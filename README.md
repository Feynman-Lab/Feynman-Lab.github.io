# Feynman Lab website

The static source for [feynman-lab.github.io](https://feynman-lab.github.io/).

GitHub Pages publishes the root of `main`. Edit the HTML and CSS directly; no build step is required. Run `python3 -m http.server 8000` from this directory to preview locally.

Ideas currently go to the public [Feynman Lab Discussions](https://github.com/Feynman-Lab/discussions/discussions). Replace the link in `submit/index.html` with a dedicated inbox when one is ready.
