# Feynman Lab website

The static source for [feynman-lab.github.io](https://feynman-lab.github.io/).

GitHub Pages publishes the root of `main`. The HTML pages are generated from `scripts/build.py` and `scripts/translations.json`; edit those files rather than the generated HTML. The site has no runtime framework or build step on GitHub Pages.

To update the site:

1. Edit the copy in `scripts/translations.json` or the layout in `scripts/build.py` and `assets/site.css`.
2. Run `python3 scripts/build.py` to regenerate all 28 pages and the sitemap.
3. Run `python3 -m http.server 8000` here to preview locally.
4. Run `python3 scripts/validate.py` before committing.

English lives at `/`. The other locales use `/zh-CN/`, `/ja/`, `/es/`, `/pt-BR/`, `/fr/`, and `/de/`. The language menu preserves the current page. Every localized page has its own canonical URL and `hreflang` links.

The homepage's ambient diagram, particle field, and section entrances are implemented in `assets/site.css` and `assets/motion.js`. Motion pauses offscreen and respects reduced-motion preferences.

The site presents Feynman Lab as an independent lab that selects ideas for public tools. A suggestion is not a commission or a promise to build. The Submit page explains the selection criteria, public/private submission routes, and what may be published. Keep those boundaries consistent whenever copy changes.

Search metadata, canonical and language links, and the sitemap are generated by `scripts/build.py`. The empty Projects pages are intentionally `noindex` and excluded from the sitemap; make them indexable when real projects are published. `assets/og-image.png` and `assets/logo-512.png` are generated by `python3 scripts/generate_social_images.py` (Pillow required). The public sitemap is `/sitemap.xml`.

When the first real project is ready, replace the empty state with a project entry and a dedicated page. Include the problem, intended users, why the lab chose it, a working tool link, usage guidance, and source code if published. Give the project page its own title, description, canonical URL, social preview, and language links only for translations that actually exist. Add the page to the sitemap and remove `noindex` from the Projects listing. Do not publish placeholder project pages or invented usage numbers.

Ideas can be sent to `torres4koo@gmail.com` from the Submit page. Public [Feynman Lab Discussions](https://github.com/Feynman-Lab/discussions/discussions) remain available as an alternative.
