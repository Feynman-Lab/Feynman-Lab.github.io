Empieza con una idea

Propón algo que valga la pena crear.

Cuéntanos un problema pequeño y el software que debería existir. Proponerlo es gratis; el laboratorio decide qué ideas explorar.

Comparte tu idea

No necesitas un plan técnico.

Estos detalles nos ayudan a entenderla:

  1. ¿Qué te gustaría que existiera?
  2. ¿Qué problema resolvería y para quién?
  3. ¿Tienes algún ejemplo o referencia?
Enviar idea por correo ↗

Se abrirá tu aplicación de correo con algunas preguntas. También puedes escribir directamente a torres4koo@gmail.com.

¿Prefieres compartirla públicamente?Publicar en GitHub Discussions ↗

Necesitas iniciar sesión en GitHub. Cualquiera puede leer las publicaciones; no incluyas información sensible.

¿Qué ideas encajan?

Herramientas web concretas, extensiones, automatizaciones y utilidades de archivos o datos que puedan ayudar a varias personas.

Los sistemas privados de empresas, aplicaciones grandes, plazos urgentes y trabajos muy personalizados no suelen encajar.

¿Qué pasa después?

Valoramos la utilidad para más de una persona, la viabilidad, el alcance y el tiempo disponible. Si queremos explorar tu idea, te contactaremos. No podemos prometer respuesta ni plazos para cada propuesta.

Proponer una idea no significa que haya sido aceptada. Los proyectos elegidos no tienen coste de desarrollo para quien los propone, pero son proyectos del laboratorio, no encargos.

Privacidad y publicación

Los correos llegan a nuestro buzón y no son públicos. Tu dirección sirve para responder; no envíes contraseñas ni datos confidenciales.

GitHub Discussions es público y requiere una cuenta de GitHub. Cualquiera puede leer lo que publiques allí.

Una idea elegida puede convertirse en una herramienta pública y su código puede abrirse. Hablaremos del alcance antes de crearla y pediremos permiso antes de publicar tu mensaje privado o identificarte.
